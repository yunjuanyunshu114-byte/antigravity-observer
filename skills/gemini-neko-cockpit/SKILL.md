# Gemini 猫娘观察台 · 反重力观察窗 (Antigravity Observer)

当用户询问上下文窗口占用、压缩次数、Token 用量、缓存命中率、模型剩余额度，或希望打开上下文观察窗口 / 调整右下角 Gemini 猫娘挂件时：

1. 直接在回复中提供原生伴生面板跳转胶囊链接：
   `[反重力观察窗](sidecar://gemini-neko-cockpit/neko-cockpit/ui.html)`
2. 右下角 Gemini 猫娘挂件交互方式：
   - **平时**：紧贴右下角静默显示 Gemini 娘主形象；AI 思考时切换「吃大米」差分；
   - **审查 / 确认 / 提问提示时**：自动切换专属「确认提醒」差分（`wait`）、播放提示音效并弹出琥珀边框思考气泡指明请求确认的项目名（`【项目名】请求主人确认啦！`）；提醒气泡为不可点击穿透并在 4 秒后自动收起，不遮挡提交按钮，点击确认或响应后自动恢复对应状态；
   - **每轮对话完成**：自动弹出气泡显示本轮使用的额度与新增 Token，10 秒后自动关闭；
   - **左键点击形象（第 1 次）**：触发 `><` 差分与音效，冒泡显示当前模型额度、上下文与 Token；
   - **左键单击气泡（第 2 次）**：切换展示「好猫猫 / 好模型」及用户自定义对话语句；
   - **左键点击气泡（第 3 次）**：关闭气泡；
   - **右键点击形象**：打开上下文/Token/额度详情卡片，可打开 **`📅 每日 Token 统计`**（18 周贡献热力图 + 7/14/30 天每日明细弹窗），或点击 **`⚙️ 挂件设置`** 切换内置双套默认皮肤（经典紫瞳 / 粉金异瞳）、自定义气泡语句、更换自定义形象（含确认差分）、开关审查确认提醒与音效、或调节大小。
3. 校验与维护命令（仓库目录下）：
   - `node setup.cjs --check` 检查安装状态
   - `node setup.cjs --doctor` 执行 Antigravity 契约自检
   - `双击安装观察窗补丁.bat`（关闭 Antigravity 后执行）应用最新主窗口补丁。
